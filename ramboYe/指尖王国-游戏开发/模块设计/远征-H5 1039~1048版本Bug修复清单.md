# 远征玩法 H5 1039~1048 版本 Bug 修复清单（供 V1 对照）

## 用途

H5 项目与 V1 项目共用"远征"玩法（`game/wmap`、`game/play` 远征相关模块、`ice_contest` 冰髓争夺战等）底层逻辑。本文整理 H5 项目 **1039~1048 版本期间（含线上热修复）** 修复的远征相关 BUG，供 V1 项目逐条对照检查、排查同类问题是否也存在于 V1 代码中。

**不包含**：纯功能新增、纯功能优化（无错误行为描述）、纯重构/代码整理、纯日志/GM 工具新增、纯协议编译提交。文末各分区附"已排查但排除"清单，供交叉核对时参考。

## 统计口径

- 仓库：`/home/cc/slgh5/gs`，范围 `git log --grep="远征" -i h5_new_tf_v1038..h5_new_tf_v1048 --no-merges`（H5 项目主线，v1048 的祖先提交，不含 `ice_`/`zjwg_` 等其他品牌分支）。
- 原始命中提交 231 条，逐条核对标题 + `git show` diff 后，合并同一 bug 的多次提交（排查日志 → 修复 → fix2 补丁等），最终整理出 **108 条独立 BUG 修复记录**，涉及约 190 个 commit。
- "版本"列含义：commit 提交所在分支前缀或 ticket 标题【】中标注的版本号；部分为跨版本 backport（如原始工单标注 1037/1041，但在 1039 分支合入修复），已在对应行备注说明。未在标题中明确标注、按提交日期与同批次上下文推断的版本已标记"推断"。
- 每条"根因"与"修复方案"均基于实际 `git show` diff 撰写，未编造；个别 diff 信息不足以完全还原根因的，已在行内如实标注。
