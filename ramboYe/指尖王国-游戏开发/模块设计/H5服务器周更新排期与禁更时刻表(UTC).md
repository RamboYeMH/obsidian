# H5 服务器架构与周一至周日更新避坑总览（UTC 版）

> **本文所有时间均为服务器时间 UTC**（北京时间 = UTC + 8）。
> 服务器的跨天、周几、配置表里的「当天第几秒」全部按 UTC 计算：`utility/time.go:33-45`（`TimeUTCNow`）、`util.NextDayTs`。
> 所以服务器的「周一 00:00」= 北京时间周一 08:00。
> 配置依据取自 gdconfig 当前分支，2026-10-28 核对。配置一改，本表就要跟着改。

![[assets/H5周更新禁更时刻表-UTC.png]]

> 动态版（输入时间自动判定本周类型、是否可更新）：[[H5服务器禁更时刻表-动态版.html]]，用浏览器打开。

## 一、核心架构记住 3 句话

1. game 是核心：单服玩法（play）、大地图（wmap）、活动（actv）都跑在 game 进程里。
2. cross 进程 ≠ 跨服大地图：cross 只同步玩家缓存。远征、GVG 的跨服大地图是跑在跨服服上的 game 进程。
3. global 是全服单点：所有跨服匹配（远征 / GVG / 联盟对决 / 巅峰竞技场）和创图都靠它。重启后要等各服重新注册，serverMap 才会恢复。

## 二、周期说明（先看这个，再看每日表）

很多玩法不是每周都有，要先判断本周属于哪种周：

| 周类型 | 周期 | 最近几期（日期为 UTC） | 配置依据 |
|---|---|---|---|
| **王座 A 周**：巅峰领地 + 王座战 20:00 | 14 天 | 周六 10-24、11-07、11-21 | `ActvOnlineCfg` 1100011（巅峰领地，周六 14:00 开，持续 8h）、1100001（王座，周六 20:00 开，持续 24h） |
| **王座 B 周**：王座战 14:00 | 14 天，与 A 周交替 | 周六 10-31、11-14、11-28 | `ActvOnlineCfg` 1100003（王座，周六 14:00 开，持续 24h） |
| **巅峰赛周**（颠覆之王） | 28 天 | 周日 16:00（北京周一 00:00）起：11-01、11-29、12-27。赛程按北京时间设计：淘汰赛北京 19:00-次日 01:00、小组赛 19:00-22:00、决赛每天 20:00 | `D2ConfigCfg` TopArena_Peak_Time `[1747584000,7,28]` |

## 三、每日通用铁律

- 🚫 **跨天禁区 23:55-00:10（北京 07:55-08:10）**：跨天定时器 `TimerTypeNextDay` 不入库（`game/play/internal/module.go:261`，`needDB=false`）。起服后只会挂到下一个 0 点，所以停机跨过 0 点时，**服务器级跨天事件 `ServerNextDay` 当天直接漏跑**。会漏掉的有：战报邮件、联盟祭坛、活动排行、远征跨天、大地图冰髓/岛屿跨天等（`game/play/internal/event.go:186-539`）。
  - 玩家级、联盟级跨天会补：玩家登录时做 `NextDayCheck`（`ctl_login.go:966`），联盟加载时也做（`munion/union.go:538`）。
- ℹ️ **每天 23:00 只是联盟 BI 快照**（`ctl_union.go:60` `UnionDailySaveHour=23` → `saveBIlogUnionDaily`），不影响玩法，**不需要每天单独设 22:50-23:40 禁区**。23:00 附近真正要避开的只有：周三（远征报名）、周四（GVG 匹配）、周五（融冰最后一轮结算）、周日（远征创图、周榜），见各日。
- ✅ **通用安全窗口 01:00-10:00（北京 09:00-18:00）**：除巅峰赛周以外，这段时间没有任何定时结算或开战。

## 四、周一至周日排期与禁更 / 可更时刻（UTC）

### 周一 Mon · 🟠 周度跨天日
- **玩法**
  - 00:00 周度跨天：联盟对决 Day1 开启（`ActvOnlineCfg` 2100001，周一开，持续 6d）、联盟总动员开启。远征开局周的下周一 00:00 正式开战（关 1）。
  - 巅峰赛周：10:00 锁定名单，10:30 锁定数据，**11:00-17:00 淘汰赛**（`TopArenaRaceCfg` type=3 course=1，以周日 16:00 为起点 +19h ~ +25h）。
- 🚫 **禁更**：周日 22:45 – 周一 00:15；巅峰赛周 09:50-17:10。
- ✅ **可更**：01:00-09:30；非巅峰赛周可放宽到 01:00-22:30。

### 周二 Tue · 🟢 全周最佳维护日
- **玩法**：联盟对决 Day2。巅峰赛周 10:30 锁定，**11:00-14:00 小组赛**（course=2，起点 +43h ~ +46h）。
- 🚫 **禁更**：23:55-00:10；巅峰赛周 10:20-14:10。
- ✅ **可更**：01:00-10:00（推荐的大版本维护窗口）；非巅峰赛周 14:30-22:00 也可以。

### 周三 Wed · 🟢 次选维护日
- **玩法**
  - 00:00 泰坦宝库开启，持续 48h 到周五 00:00（`ActvOnlineCfg` 1099403，每 7d 一轮，持续 2d）。
  - 联盟对决 Day3。
  - 巅峰赛周 11:30 锁定，**12:00 决赛第 1 轮**（course=3，起点 +68h，之后每 24h 一轮）。
  - 远征开局周 **23:00 远征报名开启**（`ctl_battlefield_cmd.go:123-126`：报名日按周四 0 点算，实际提前 1h）。
- 🚫 **禁更**：23:55-00:10；巅峰赛周 11:20-15:10；远征开局周 22:50-23:10。
- ✅ **可更**：01:00-10:00。

### 周四 Thu · 🟡 GVG 报名 & 匹配日
- **玩法**
  - **00:00-23:00 GVG 巨龙之战报名**（`ActvOnlineCfg` 5000001，周四开）。**23:00 报名截止并触发 global 匹配**（`gvg_sign_up/api.go:57-58`，`GVG_Match_Start_Time=82800000ms`）。
  - 泰坦宝库 Day2，联盟对决 Day4。
  - 远征开局周 00:00 进入预告期。
  - 巅峰赛周 12:00 决赛第 2 轮。
- 🚫 **禁更**
  - **22:45-23:15 global 必须在线**：报名记录入库，global 重启后 `GvgMatchStart` 会从库里恢复匹配定时器（`global/internal/ctl_match_gvg.go:337-347`、`match/gvg/mgr.go:106-108`），所以**白天单独重启 global 是安全的**。真正的风险是 23:00 那一刻 global 不在线：起服时 `nextTime<=0` 直接 return，本周匹配不会再跑。
  - 23:55-00:10；巅峰赛周 11:20-15:10。
- ✅ **可更**：01:00-10:00 或 15:30-22:00。

### 周五 Fri · 🔴 GVG 开战日

- 结论：**严禁例行发版**。

## 五、更新 / 重启服务器会影响哪些玩法（本次未核对代码，沿用原文）

1. 【跨服丢积分（极高危）】跨服战场积分靠 NATS 实时发回原服。如果原服在重启、跨服还在打，玩家的远征积分 / 战令奖励会直接丢包。
2. 【直接判负 / 中断】个人竞技场正在打的玩家断线判负；塔防局内未点确认的「三选一天赋」清空；家园拜访被踢回主城。
3. 【大地图与远征重置】跨服 game 重启会强制重跑初始化（未占领建筑野怪重置，王座 / 火车 / 祭坛 / 复活泉重绑，冰髓战水晶塔锁敌缓存清空）；正在交火的多回合战报前半截明细和 Boss 伤害排行重置。

## 六、标准停起服顺序（本次未核对代码，沿用原文）

- ✅ 停服：gate ➔ 跨服 game ➔ 本服 game ➔ 最后 global / cross
- ✅ 起服：door / global / cross ➔ 本服 game ➔ 确认 global 的 serverMap 注册齐备 ➔ 最后起跨服 game 与 gate
