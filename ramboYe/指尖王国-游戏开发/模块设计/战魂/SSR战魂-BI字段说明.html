SSR战魂：BI 埋点与字段

分支 h5_new_tf_v1051_remote_fight_light · 2026-10-08 · 代码位置 game/play/internal/ctl_war_soul.go、mplayer/player_bi.go、game/bi/def

结论

  • 战魂有 2 张独立 BI 表：war_soul_upgrade（战魂升级成功写一条）、war_soul_node（觉醒刻印节点解锁成功写一条）。
  • 资产流水里有 3 个战魂 reason：628 升级消耗碎片、629 升级消耗英雄本体、630 解锁高级节点消耗。
  • 独立表的 related_id 与资产流水的事件 ID 都是同一个 operationID，可以用它把同一次升级的流水关联起来。
  • 觉醒刻印节点解锁单独写入 war_soul_node 表，见文末。

一、独立 BI 表 war_soul_upgrade战魂升级流水

觉醒刻印节点解锁（独立表 war_soul_node）

写入函数：(*Player).BILogWarSoulNodeUnlock（mplayer/player_bi.go）；触发位置：OnWarSoulNodeUnlockReq 解锁成功后。普通节点、高级节点都记。

  • related_id：本次解锁的 operationID，高级节点与资产流水 630 的事件 ID 相同。
  • hero_id / hero_cfg_id：SSR 英雄唯一 ID / 配置 ID。
  • node_id：解锁的节点 ID。
  • war_soul_lvl：解锁时的战魂等级。

表名常量：def.BILogFileWarSoulNode = "war_soul_node"（game/bi/def/table.go）。同时修复了升级流水 old_lvl 之前没写入的问题。
