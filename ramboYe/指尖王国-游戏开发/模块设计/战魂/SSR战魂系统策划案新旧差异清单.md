# 《指尖王国》SSR战魂系统策划案新旧差异清单

## 一、新增内容清单

| 分类 | 新增内容 | 新版位置 | 开发影响 |
|---|---|---|---|
| 系统组成 | 明确战魂系统由战魂等级、战魂经验、英雄属性、觉醒刻印和阵营属性构成。 | 一、系统定位 | 需要把“觉醒刻印”和“阵营属性”作为正式模块接入，而不是只做展示文案。 |
| 成长记录 | 明确战魂成长记录在 SSR 英雄身上，不记录在共生英雄身上，不开放给非 SSR 英雄。 | 一、系统定位 | SSR 数据结构需要保留等级、经验、属性、刻印节点状态。 |
| 当前配置 | 明确当前配置为 8 个 15 星英雄显示入口，10 个 15 星英雄满足正式数量门槛。 | 三、系统简介；4.2 系统解锁条件 | 入口显示和正式可用要分两个配置值判断。 |
| 觉醒刻印 | 新增觉醒刻印作为战魂详情页中的阵营属性成长区域。 | 4.7 觉醒刻印与阵营属性规则 | 需要新增或复用刻印节点配置、节点状态和节点展示。 |
| 普通节点 | 普通节点达到战魂等级后无需道具即可解锁并生效。 | 4.7 觉醒刻印与阵营属性规则 | 普通节点应支持自动解锁，不需要道具弹窗。 |
| 高级节点 | 高级节点达到等级后进入可解锁状态，需要消耗指定数量战魂结晶后才解锁并生效。 | 4.7 觉醒刻印与阵营属性规则 | 高级节点需要道具数量校验、消耗、解锁状态保存。 |
| 战魂结晶 | 新增高级节点消耗道具“战魂结晶”，道具足够时可解锁，不足时进入获取途径。 | 4.7；5.3；5.4 | 需要接入道具拥有数量、扣除和获取途径入口。 |
| 高级节点道具弹窗 | 新增弹窗标题“觉醒刻印”，展示需要消耗的战魂结晶数量和当前拥有数量。 | 5.3 高级节点道具使用弹窗 | 需要新增独立弹窗，区别于升级确认弹窗。 |
| 道具按钮颜色 | 高级节点弹窗按钮显示图标加需求数量；道具足够显示绿色，不足显示红色。 | 4.7；5.3 | 按钮状态需要由拥有数量和需求数量共同决定。 |
| 无进度条要求 | 高级节点道具使用弹窗无需显示进度条。 | 4.7；5.3 | 不应沿用旧的进度条式阶段奖励或养成反馈。 |
| 节点解锁反馈 | 节点解锁成功后播放解锁反馈页，展示本次解锁的阵营属性和战力变化。 | 4.7；5.8 | 需要新增阵营属性解锁反馈页。 |
| 战魂等级规则 | 新增战魂等级通过战魂经验提升、经验只来自英雄碎片和英雄本体、满经验自动升下一级、满级后不能投放材料。 | 4.6 战魂等级规则 | 需要补齐等级经验、自动升级、满级禁投和满级提示逻辑。 |
| 觉醒刻印进度 | 新增觉醒刻印经验进度与战魂经验进度共享的说明。 | 4.6 战魂等级规则 | 刻印节点开放进度应与战魂等级或经验进度联动。 |
| 满级提示 | 战魂达到等级上限后，升级页显示“当前英雄战魂等级已达上限”。 | 4.6；5.5 | 升级页需要满级状态页或禁用态。 |
| 通用碎片 | 新版单独明确通用英雄碎片可以作为战魂升级材料。 | 4.8 材料范围；4.9 材料投放页展示规则 | 材料筛选和材料经验配置需要包含通用英雄碎片。 |
| 材料选择规则 | 新增独立“材料选择规则”章节，拆分碎片选择、本体多选、页签保留和退出重置。 | 4.10 材料选择规则 | 需要独立处理碎片数量、本体多选和跨页签保留。 |
| 碎片单选框 | 英雄碎片同一时间只显示一个当前选中的碎片选择框。 | 4.10 材料选择规则 | 碎片页不能同时展开多个数量选择框。 |
| 本体多选 | 英雄本体可以同时选择多个。 | 4.10 材料选择规则；5.5 材料投放页 | 本体页需要支持多选状态，不是单选。 |
| 高价值英雄提示配置 | 高星提示门槛当前配置为 13 星。 | 4.11 高价值英雄提示规则 | 高价值本体风险提示需要读取配置，默认按 13 星理解。 |
| 一键选择确认行为 | 一键选择遇到高星本体时，确认后继续选中高星本体，取消后排除高星本体。 | 4.12 一键选择规则 | 一键选择弹窗需要有确认和取消两种不同结果。 |
| 筛选项 | 新增品质筛选内容为 B、A、S、SS、SS+，取消某品质后当前页签不显示该品质材料。 | 4.13 筛选规则；5.5 材料投放页 | 筛选层需要支持多选和当前页签内刷新。 |
| 确认弹窗取消保留 | 升级确认弹窗点击取消后回到材料投放页，并保留之前玩家勾选的材料选择。 | 4.14 升级确认规则；5.6 升级确认弹窗 | 取消弹窗不能清空当前选择。 |
| 未选材料提示 | 确认升级按钮在未选择材料时置灰，点击后提示“请先选择投放材料”。 | 5.5 材料投放页 | 按钮虽然置灰表现，但仍要有点击提示反馈。 |
| 红点消失条件 | 玩家进入战魂系统后，如果无可用材料，退出后红点消失。 | 4.16 红点规则 | 红点状态需要结合玩家进入行为和材料可用情况刷新。 |
| 节点红点 | 节点达到等级且满足可解锁条件时，战魂入口显示红点。 | 4.16 红点规则 | 红点不再只跟升级材料相关，还要跟刻印节点可解锁相关。 |
| 商业化展示 | 新增战魂结晶不足时通过获取途径进入礼包或活动、常驻礼包页可展示战魂相关礼包。 | 5.9 商业化展示 | 商业化入口与获取途径、礼包页、活动页需要打通。 |
| 系统帮助 | 新增系统帮助说明，覆盖解锁、材料、升级、刻印、属性失效和不可返还提示。 | 5.10 系统帮助说明 | 需要新增或更新帮助弹窗文案。 |

## 二、调整内容清单

| 分类 | 旧版内容 | 新版内容 | 开发影响 |
|---|---|---|---|
| 整理日期 | 2026-07-11 | 2026-09-01 | 以新版日期对应的规则为准。 |
| 系统定位 | 系统解锁后，SSR 当前绑定的共生英雄达到 15 星时，可以开启、升级并获得属性。 | 改为先描述系统构成和成长记录，具体使用条件下沉到系统简介和 4.2、4.3。 | 条件判断需要按新版 4.2、4.3 执行。 |
| 设计目的 | 强调规则理解简易性、开辟商业化道具、阵营节点和领主档案皮肤。 | 改为强调非 SSR 材料回收、觉醒刻印成长线、刻印道具、礼包活动投放、阵营属性和战力反馈。 | 商业化和成长目标从“皮肤/收集”转向“战魂结晶/刻印/礼包活动”。 |
| 系统简介 | 玩家拥有指定数量 15 星英雄后，战魂系统解锁。 | 改为入口显示数量和正式解锁数量分别由配置控制，并给出 8 和 10 的当前配置。 | 不能只用一个 N 判断入口和解锁。 |
| 详情页展示 | 旧版详情页展示战魂等级、经验进度、当前属性、阵营加成、共生英雄状态和材料投放入口。 | 新版详情页展示战魂等级、战魂经验、战魂战力、英雄属性、觉醒刻印、阵营属性和系统帮助入口。 | UI 展示字段需要调整，重点补战魂战力和觉醒刻印。 |
| 养成对象 | 战魂等级、经验、属性记录在 SSR 身上。 | 记录内容扩展到战魂等级、战魂经验、战魂属性和刻印节点。 | 需要保存刻印节点状态。 |
| 共生变更 | 更换共生英雄后等级和经验不清空。 | 更换或解除共生后，等级、经验、属性和刻印节点状态都不清空。 | 解除共生也不能清战魂成长数据。 |
| 属性对象 | 战魂属性只加给对应 SSR。 | 战魂属性中的战力和带兵量只加给对应 SSR，觉醒刻印属性按 buff 加给对应阵营或当前 SSR。 | 属性生效对象需要按属性类型拆分。 |
| 使用条件 | 章节标题为“SSR能否使用战魂系统/享受战魂系统加成的条件”。 | 调整为“战魂使用条件”，并补充满足/不满足时对升级、属性生效、刻印解锁的影响。 | 需要把刻印解锁纳入使用条件校验。 |
| 战魂状态 | 旧版偏向入口锁定后的具体提示。 | 新版增加“未达到入口显示要求时不显示入口”，并把已有码等级但条件不满足时的入口等级展示写清楚。 | 入口状态至少包含不显示、锁定、点亮、带等级锁定等状态。 |
| 属性生效范围 | 旧版写英雄属性加 SSR、阵营属性加所在阵营所有英雄，属性在英雄队伍参战玩法生效。 | 新版拆成英雄属性、阵营属性，并明确必须满足战魂使用条件且 SSR 被编入队伍参与战斗时生效。 | 生效校验要同时看使用条件和参战状态。 |
| 节点命名 | 旧版为阵营加成、普通节点、阶段节点。 | 新版主要调整为觉醒刻印、普通节点、高级节点、阵营属性。 | 代码、配置、UI 文案建议统一到新版术语。 |
| 节点解锁 | 旧版阶段节点达到等级后消耗指定道具解锁，不足时打开获取途径。 | 新版高级节点达到等级后消耗战魂结晶；足够时可直接解锁，不足时进入获取途径；弹窗无进度条。 | 需要按战魂结晶和道具使用弹窗重做阶段节点逻辑。 |
| 材料范围 | 旧版在同一条中说明非 SSR 碎片包含 B、A、S、SS、SS+ 和通用碎片。 | 新版把非 SSR 品质和通用英雄碎片拆开说明。 | 材料配置上仍需保留通用碎片，但文档表达更清晰。 |
| SSR 材料展示 | 旧版只说 SSR 本体和 SSR 碎片不能作为材料。 | 新版补充 SSR 本体和 SSR 碎片也不在投放页展示。 | SSR 材料需要在投放页源头过滤。 |
| 空状态文案 | 旧版为空时显示“暂无可投放材料”，并保留获取途径入口和系统帮助入口。 | 新版为空时显示“暂无可用材料”。 | 空状态文案需要改为新版；旧版保留入口的要求不再出现在新版正文。 |
| 材料消耗 | 旧版“材料消耗规则”包含可使用、确认消耗、高星本体风险提示。 | 新版拆分为材料选择规则和高价值英雄提示规则。 | 逻辑拆分后，选择态和风险态需要分开实现。 |
| 一键选择文案 | 旧版给了 13 星及以上、指定星级、13 星以上三种提示分支。 | 新版统一为“本次一键选择包含{0}星或更高星级英雄本体，该类道具价值较高，取消后将排除选择，确认后将继续选中。” | 多分支文案可收敛为新版单一文案。 |
| 一键选择范围 | 旧版一键全选只作用于当前页签。 | 新版一键选择只作用于当前页签和当前筛选结果。 | 一键选择必须受筛选结果影响。 |
| 筛选规则 | 旧版只写初次进入页面时所有选项默认全选、筛选只作用当前页签。 | 新版明确筛选为品质多选，包含 B、A、S、SS、SS+，首次打开筛选时默认全选。 | 筛选 UI 和默认状态要按筛选层处理。 |
| 升级确认文案 | 旧版使用“本次已选择英雄碎片：{碎片数量} 个。本次已选择英雄本体：{本体数量} 个。” | 新版使用“本次已选择英雄碎片：{0} 个，本次已选择英雄本体：{1} 个，消耗后材料不可返还，是否确认继续升级？” | 占位符和标点应按新版多语言文案同步。 |
| 高星确认提示 | 旧版写确认弹窗展示是否包含大于等于 13 星本体。 | 新版改为在确认升级弹窗追加明确提示：“本次选择中包含13星或以上英雄本体，材料价值较高，是否继续？” | 需要在升级确认弹窗中追加二段提示，而不是只显示布尔结果。 |
| 确认时检查 | 旧版检查 SSR 是否处于可升级状态和材料是否仍可消耗。 | 新版拆分为当前 SSR 是否仍满足升级条件、材料是否存在/足够/可消耗、失败提示、失败后返回选择界面。 | 失败提示和返回路径要作为明确异常流程实现。 |
| 红点规则 | 旧版红点包含正式解锁、有可升级材料、满级不显示升级红点。 | 新版调整为正式可用显示红点、无材料进入后红点消失、有可投放材料显示红点、节点可解锁显示红点。 | 红点来源新增刻印节点可解锁，同时增加无材料进入后的消点逻辑。 |
| SSR 详情入口 UI | 旧版只说右侧功能入口新增战魂入口。 | 新版补充入口位置在天赋入口下方。 | 入口排布需要按新版位置落位。 |
| 战魂主页命名 | 旧版章节名为“战魂主页”。 | 新版章节名为“战魂详情页”。 | 页面命名和导航可按“详情页”统一。 |
| 材料页顶部 | 旧版材料页主要描述页签和选择交互。 | 新版新增顶部展示升级前后战魂等级、经验、战力和属性变化。 | 材料页需要实时预览升级收益。 |
| 商业化 | 旧版仅保留商业化拍脸图。 | 新版扩展为商业化展示，包含获取途径进入礼包或活动、常驻礼包页展示战魂相关礼包。 | 商业化链路需要接入礼包和活动入口。 |

## 四、开发实施关注点

| 关注点 | 说明 |
|---|---|
| 入口状态 | 至少需要支持未显示、锁定、点亮、已有战魂等级但锁定、已有战魂等级且可进入等状态。 |
| 数据归属 | 战魂等级、经验、属性、刻印节点状态都归属 SSR 英雄，不随共生英雄更换或解除而清空。 |
| 使用条件 | 战魂升级、属性生效、觉醒刻印继续解锁都需要校验当前 SSR 是否满足战魂使用条件。 |
| 节点系统 | 普通节点自动生效，高级节点消耗战魂结晶；高级节点不足时进入获取途径，足够时解锁并反馈属性与战力变化。 |
| 材料页签 | 英雄碎片和英雄本体是两个独立页签，切换页签时保留另一页签选择，退出材料投放页后重置本次选择。 |
| 材料筛选 | 一键选择和取消一键选择都只作用于当前页签和当前筛选结果。 |
| 风险提示 | 13 星及以上英雄本体的单选和一键选择都需要风险提示；升级确认弹窗还需要追加高价值材料提示。 |
| 红点来源 | 红点来源包括正式可用、存在可投放材料、刻印节点可解锁；无材料进入后退出需要消点。 |
| 多语言文案 | 新版明确的关键文案包括“暂无可用材料”“请先选择投放材料”“材料状态已变化，请重新选择”“本次选择中包含13星或以上英雄本体，材料价值较高，是否继续？”。 |
| 商业化入口 | 战魂结晶不足时的获取途径需要能进入礼包或活动，常驻礼包页可展示战魂相关礼包。 |
