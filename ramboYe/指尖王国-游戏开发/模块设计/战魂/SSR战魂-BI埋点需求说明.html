SSR战魂 BI 需求清单

一、战魂升级

日志：war_soul_upgrade。每次战魂升级成功时记录。

字段内容
related_id本次升级操作 ID
hero_id被升级 SSR 的英雄唯一 ID
hero_cfg_id被升级 SSR 的英雄配置 ID
old_lvl升级前战魂等级
new_lvl升级后战魂等级
old_exp升级前战魂经验
new_exp升级后战魂经验
add_exp本次增加的战魂经验
frag_detail本次消耗的英雄碎片明细（道具ID*数量）
item_detail本次消耗的道具明细（英雄宝箱等非碎片道具，道具ID*数量）
hero_detail本次消耗的英雄本体明细
max_star本次消耗英雄本体中的最高星级

二、觉醒刻印节点解锁

日志：war_soul_node（独立表）。普通节点和高级节点解锁成功时都记录。

字段内容
related_id本次解锁操作 ID；高级节点与资产流水 630 的事件 ID 相同
hero_id解锁节点的 SSR 英雄唯一 ID
hero_cfg_id解锁节点的 SSR 英雄配置 ID
node_id本次解锁的节点 ID
war_soul_lvl解锁时的战魂等级

三、资产消耗

reason ID内容
628战魂升级消耗英雄碎片
629战魂升级消耗英雄本体
630高级节点解锁消耗
