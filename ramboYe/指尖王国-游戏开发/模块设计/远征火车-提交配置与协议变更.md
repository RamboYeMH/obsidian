# 远征火车提交、配置与协议变更

## 结论

- 基于 `ice_v1102` 当前可达历史，提交标题直接命中“火车/列车”的提交共 **118 个**。
- 其中 **58 个**位于 2025-02-18～2025-03-13，完成火车主体、燃料运输、驻防/集结、保护、存盘、王座攻击和排名；**52 个**位于 2025-03-14～2025-05-15，集中处理玩法联调、战斗/预警/任务/通知和边界问题；**8 个**位于 2025-09-19～2026-01-29，处理体力、编队显示以及击破掉燃料次数限制。
- 标题直接命中的提交里，真正修改 `.proto` 源文件的有 **19 个**。生成的 `*.pb.go`、`msg.go` 和 `msgid.def` 是随协议重新生成的产物，不应重复算作独立协议设计。
- 表字段的有效变更集中在 `ExpPlayBookCfg`、`ExpGridCfg`、`ExpRailwayCfg`、`PoisonMapEventTaskCfg`、`PoisonMapSpecialEventCfg`、`ExpTrainDropPositionCfg`、`ExpTrainTotalRewardCfg`；2026 年追加 `ExpRandomTaskCfg.StartTime/EndTime`。

git log --date=short --pretty=format:'%h %ad %s' \

## 注意事项

1. `ExpRailwayCfg.TotoalScore`、`ExpeditionTrainTotoalScore`、`ExpTrainInfo.RailywayCfgId`、`ExpCampTrainFuleAddNtf` 都保留了历史拼写错误；客户端、配置和服务端必须按现名兼容，不能直接改名。
2. `ExpTrainInfo` 早期多次调整字段号，并注释掉 `campRewardsInfo/eventTp`。跨版本客户端联调时应以最终 proto 字段号为准，不要按最早提交里的字段号实现。
3. `b43beb6fcc` 同步了大量 proto/生成文件，但语义上和火车有关的新增仅是 `SelfProc_TrainArrived = 25`；其余大多是格式化或全量生成噪音。
4. 当前工作区有用户未跟踪文件 `test.go`，本次只读分析未修改项目代码。
