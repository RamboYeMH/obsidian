# Linux 目录结构：从 `/` 开始

关联：[[00-操作系统学习主页]]、[[01-学习路线]]、[[02-学习日志]]

Linux 的目录组成一棵以根目录 `/` 为起点的树。不同的磁盘、U 盘和网络文件系统都会被挂载到这棵树的某个目录中；因此，Linux 不用 `C:`、`D:` 作为访问入口。

```text
/
├── bin       常用命令（现代系统通常链接到 /usr/bin）
├── boot      启动所需的内核和引导配置
├── dev       设备文件
├── etc       系统级配置
├── home      普通用户的家目录
├── lib       共享库与内核模块
├── media     可移动介质的挂载位置
├── mnt       临时手动挂载位置
├── opt       可选的第三方软件
├── proc      进程与内核状态的虚拟文件系统
├── root      root 用户的家目录
├── run       本次开机以来的运行时状态
├── sbin      系统管理命令
├── srv       服务对外提供的数据
├── sys       设备与内核对象的虚拟文件系统
├── tmp       临时文件
├── usr       大部分用户态程序、库和文档
└── var       经常变化但通常需保留的数据
```

## 先掌握这七个目录

| 目录 | 它代表什么 | 记忆方式 |
| --- | --- | --- |
| `/etc` | 全局配置 | 系统和服务“按什么规则运行” |
| `/home` | 普通用户文件 | 每个普通用户自己的工作区 |
| `/usr` | 软件、库、文档 | 大多数安装好的用户态软件在这里 |
| `/var` | 日志、缓存、服务数据 | 会变化、却通常不该随便删除 |
| `/tmp` | 短期临时文件 | 可被系统清理的中间数据 |
| `/proc` | 内核动态提供的进程信息 | 观察进程和内核的窗口，不是真实磁盘文件 |
| `/dev` | 设备的文件接口 | 磁盘、终端等也能像文件一样被操作 |

## 容易混淆的地方

### `/`、`/root` 与 `/home`

`/` 是整个目录树的根；`/root` 是管理员用户 `root` 的家目录；`/home/alice` 则是普通用户 `alice` 的家目录。`/root` 不是根目录。

### `/bin` 与 `/usr/bin`

两者都放可执行命令。现代发行版为保留旧路径兼容性，常让 `/bin` 链接到 `/usr/bin`；所以看到链接是正常现象。

### `/tmp` 与 `/var`

`/tmp` 适合随时可丢弃的临时内容；`/var` 通常存日志和服务数据，常需要跨重启保存。

### `/proc` 与 `/sys`

它们是内核在访问时即时生成的虚拟文件系统。`/proc/<PID>` 描述一个进程；`/sys` 描述设备、驱动和内核对象。

## 本课实验

```bash
pwd
ls /
ls -ld /bin /sbin /lib
readlink -f /bin
echo $$
ls /proc/$$
ls -l /proc/$$/fd
df -hT
mount | head
```

思考：`$$` 对应的为什么是 `/proc/$$`？`df -hT` 中的挂载点如何接入目录树？

## 本课结论

不必死背全部目录。先记住：`/etc` 管配置、`/home` 放用户文件、`/usr` 放软件、`/var` 放可变持久数据、`/proc`/`/sys` 是内核窗口、`/dev` 是设备入口。
