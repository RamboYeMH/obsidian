# 操作系统学习路线

关联：[[00-操作系统学习主页]]、[[02-学习日志]]

## 阶段 0：准备与系统观察

目标：能区分用户态/内核态，知道程序通过系统调用请求内核服务。

- 阅读：OSTEP 导论与虚拟化导论。
- 观察：`ps aux`、`top`、`free -h`、`lsof -p <pid>`、`cat /proc/<pid>/status`。
- 实验：启动一个程序，记录它的 PID、线程数、内存和打开文件。
- 验收：能说清进程、程序、线程、文件描述符各是什么。

## 阶段 1：进程、线程与调度

目标：理解进程创建、状态转换、上下文切换与调度的基本取舍。

- 阅读：OSTEP 进程、CPU 调度章节。
- 实验：编写或阅读一个创建子进程与等待子进程的示例；用 `strace` 观察系统调用。
- 验收：能解释 `fork`、`exec`、`wait` 的分工，以及阻塞为何会让出 CPU。

## 阶段 2：虚拟内存

目标：理解地址空间、页、缺页、栈、堆和 `mmap`。

- 阅读：OSTEP 内存虚拟化章节。
- 观察：`cat /proc/<pid>/maps`、`free -h`、`vmstat 1`。
- 实验：比较普通文件读取与内存映射读取；记录 RSS 与映射区域变化。
- 验收：能解释虚拟地址不等于物理内存、为什么会发生缺页。

## 阶段 3：文件系统与 I/O

目标：掌握文件描述符、目录项、inode、页缓存和阻塞 I/O 的关联。

- 阅读：OSTEP 持久化章节。
- 观察：`ls -li`、`lsof`、`strace -e trace=file <command>`。
- 实验：创建硬链接和软链接，比较 inode 与删除后的行为。
- 验收：能解释“删除文件但磁盘空间未释放”的常见原因。

## 阶段 4：并发与进程间通信

目标：理解竞态、锁、条件变量、死锁与常见 IPC。

- 阅读：OSTEP 并发章节。
- 实验：实现生产者—消费者；故意制造竞态，再用同步机制修复。
- 验收：能列出死锁四个必要条件，并解释锁的粒度取舍。

## 阶段 5：网络与隔离

目标：从 socket 到容器，理解内核如何提供网络与资源隔离。

- 主题：socket、TCP 状态、namespace、cgroup。
- 实验：用 Docker 查看容器进程、网络命名空间与资源限制。
- 验收：能解释容器不是虚拟机，以及容器隔离依赖的内核能力。

## 推荐资料

- OSTEP：主教材，按上述阶段阅读。
- MIT 6.S081 / xv6：理解内核实现时使用。
- The Linux Programming Interface：从 Linux API 深入时查阅。
- Brendan Gregg 的 Linux 性能资料：性能观察与诊断。
