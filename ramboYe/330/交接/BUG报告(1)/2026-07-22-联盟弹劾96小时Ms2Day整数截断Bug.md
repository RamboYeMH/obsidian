# 联盟弹劾：离线96小时仍提示"未满96小时"

## 问题摘要

**区服**: 752  
**反馈玩家**: 9803629（娃哈哈）  
**盟主ID**: 9801940  
**症状**: 盟主最后登录 2026-07-18 10:10:54，截至 7月22日已离线约95小时，点击弹劾仍提示"未满96小时无法进行弹劾"。本地调时间到7月23日后弹劾正常。

**根因**: `utility/time.go:57` `Ms2Day()` 整数除法截断，95.8小时 → `95.8/24 = 3.99` → int = 3天，配置要求 ≥4天，触发阻断。

## 排查过程

### 1. 代码定位

弹劾入口: `game/play/internal/ctl_union.go:3234` `OnUnionLeaderDismissReq`
- 检查盟主在线: line 3260 → `IsOnline()` → false → 通过
- 调用不活跃判断: line 3272 → `unionMemberIsNoActive()`

核心判断: `game/play/internal/ctl_union.go:3299` `unionMemberIsNoActive()`
```go
offOnlineTs := nowTimer - lastActiveTs          // line 3328: 离线毫秒数
offOnlineDay := utility.Ms2Day(offOnlineTs)      // line 3330: 毫秒→天
offOnlineDayLimits := gdconf.GetD2ConstCfgIntArray(gdconf.UnionImpeachDays) // line 3335
offOnLineDayLimit := offOnlineDayLimits[0]       // line 3337: 配置天数阈值
if offOnlineDay < int64(offOnLineDayLimit) {     // line 3343: 天数不足 → 阻断
```

### 2. 分叉点

`utility/time.go:56-58`:
```go
func Ms2Day(dura int64) int64 {
    return dura / 1000 / 60 / 60 / 24   // 整数除法！
}
```

### 3. 数值验证

| 场景 | 离线时长 | Ms2Day 返回值 | 阈值 | 结果 |
|------|---------|-------------|------|------|
| 7/18 10:10 → 7/22 09:00 | ~94.8h | `341280000 / 86400000 = 3` | 4 | ❌ 阻断 |
| 7/18 10:10 → 7/22 10:11 | ~96.0h | `345660000 / 86400000 = 4` | 4 | ✅ 通过 |
| 7/18 10:10 → 7/23 05:00 | ~115h | `414000000 / 86400000 = 4` | 4 | ✅ 通过 |

**整数截断最大误差**: 当离线时长为 `4×24h - 1ms = 95h59m59.999s` 时，`Ms2Day` 仍返回 3，需额外等待最多 23h59m。

## 修复建议

**文件**: `game/play/internal/ctl_union.go`，`unionMemberIsNoActive` 函数

**方案**: 用 `Ms2Hour`（小时级精度）替代 `Ms2Day`（天级精度），误差从最大 23h59m 降至 < 1h：

```go
// 行 3330: 改前
offOnlineDay := utility.Ms2Day(offOnlineTs)

// 行 3330: 改后
offOnlineHour := utility.Ms2Hour(offOnlineTs)

// 行 3337-3343: 改前
offOnLineDayLimit := offOnlineDayLimits[0]
// ...
if offOnlineDay < int64(offOnLineDayLimit) {

// 行 3337-3343: 改后
offOnlineHourLimit := int64(offOnLineDayLimit) * 24
if offOnlineHour < offOnlineHourLimit {
```

> 不改 `Ms2Day` 本身，避免影响其他调用者。

## 影响范围

所有联盟弹劾场景。盟主离线时间接近 96h 整数倍（~96h, ~192h, ~288h…）时，玩家可能被 `Ms2Day` 截断卡住最多 23h59m。
