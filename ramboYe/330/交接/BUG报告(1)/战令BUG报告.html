根因结论

新增字段 ReopenScoreMap 未做存量数据兼容，nil map 写入引发 panic

1042 版本在 PlayerQuestProgress 中新增 ReopenScoreMap map[int32]int32 字段， 用于记录满级循环奖励的已领次数。MongoDB 加载存量数据时，该字段缺失，Go bson 驱动将其置为 nil（而非空 map）。读取 nil map 安全，但写入触发 runtime panic: assignment to entry in nil map（ctl.go:274）。 框架 chanrpc recover 截获 panic，defer 发出空奖励的 ack，玩家界面显示成功但无奖励、积分不变， 且每次点击重复触发 panic，形成幂等失败循环。

工程规范要求

规范：持久化结构体的 map 字段必须通过封装方法访问，禁止直接读写

Go bson 反序列化对文档中缺失的 map 字段赋 nil，读安全但写 panic。 为从根本上杜绝此类问题，凡 持久化结构体（存入 MongoDB 的 struct）中的 map 字段， 必须提供封装的 getter / setter 方法，在方法内部统一处理 nil 初始化。 业务代码禁止直接通过 progress.SomeMap[k] 方式读写，必须调用对应方法。

✗ 修复前：直接访问 map，nil map 写入 panic
keyCnt := totalCnt - progress.ReopenScoreMap[k]   // 读 nil map → 0，看似安全
progress.ReopenScoreMap[k] = totalCnt              // 写 nil map → PANIC
✓ 修复后：通过封装方法访问，内部处理 nil
// GetReopenScoreCnt 获取 key 对应的满级循环已领取次数；内部保证 map 已初始化，避免 nil map panic
func (qp *PlayerQuestProgress) GetReopenScoreCnt(key int32) int32 {
    if qp.ReopenScoreMap == nil {
        qp.ReopenScoreMap = map[int32]int32{}
        qp.MakeDirty()
    }
    return qp.ReopenScoreMap[key]
}

// SetReopenScoreCnt 设置 key 对应的满级循环已领取次数；内部保证 map 已初始化，避免 nil map panic
func (qp *PlayerQuestProgress) SetReopenScoreCnt(key, val int32) {
    if qp.ReopenScoreMap == nil {
        qp.ReopenScoreMap = map[int32]int32{}
        qp.MakeDirty()
    }
    qp.ReopenScoreMap[key] = val
}

// 业务代码改用方法调用
keyCnt := totalCnt - progress.GetReopenScoreCnt(k)
progress.SetReopenScoreCnt(k, totalCnt)
getter / setter 内部的 nil 检查是兜底保障：即使 AfterLoad 未覆盖某些路径（如 框架懒加载、测试环境），写入也不会 panic，并会自动触发 MakeDirty 完成一次性修复写回。
规范
规范适用范围：持久化结构体中的所有 map 字段
反例 → 正例
✗ 禁止：直接读写持久化结构体的 map 字段
val := progress.DataMap[key]         // 虽然安全，但无统一保障
progress.DataMap[key] = newVal       // nil map → panic
progress.ReopenScoreMap[k] = cnt     // ← 本次事故根因
✓ 要求：所有 map 字段提供 getter/setter，内部处理 nil
val := progress.GetSomeMap(key)      // getter 内部 nil 检查
progress.SetSomeMap(key, newVal)     // setter 内部 nil 检查 + 写入
progress.SetReopenScoreCnt(k, cnt)   // ← 修复后写法

此规范已记录到团队 Go 编码规范文档，适用于所有 +deepcopy-gen=true 标记的持久化结构体。
