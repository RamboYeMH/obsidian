# BUG — game288 充值回调失败（cluster.GetByID 找不到节点）

## 现象

玩家反馈充值不到账（订单 `6a6090b200040ef0`，game288 服，玩家 3946492）。

ELK 日志显示 pay1 三次回调失败：

```
2026-07-22 21:50  error  handler.go:68  SendGiftToGameServer failed, err: get server node: 288 failed
2026-07-22 21:55  error  handler.go:68  SendGiftToGameServer failed, err: get server node: 288 failed
2026-07-22 22:00  error  handler.go:68  SendGiftToGameServer failed, err: get server node: 288 failed
```

## 根因

`pay/base/internal/handler.go:87` 调用 `cluster.GetByID("game", 288)` 返回 nil — game288 节点在 etcd 集群注册表中不存在。

```
gs := cluster.GetByID(gconf.GameServerName, sid)
if gs == nil {
    return fmt.Errorf("get server node: %d failed", post.Sid)
}
```

21:50~22:00 期间 game288 从 etcd 注册表中消失（进程重启或心跳超时导致 lease 过期），22:05 恢复后重试成功。

当天上午 10 点有服务器维护，但问题发生在 12 小时后，与维护无直接因果。更可能是 game288 在 21:50 左右短暂宕机/重启，或 etcd 心跳网络抖动导致节点被摘除。

## 最终结果

22:05 重试成功，`ctl_d2iap.go:285 LoadPlayerOnBuyGift` 和 `OnBuyProductPaidReq` 完成发货，玩家应已收到礼包。

订单信息：

- 玩家 ID：3946492
- 服务器：game288

- SDK 订单号：2676151608720260722

## 修复/改善

- 常规问题，无代码改动。pay 服务的重试机制正常工作（最终投递成功）。
- 建议：监控 game288 节点在 etcd 中的注册状态，异常摘除时告警。
- 验证方式：确认玩家 3946492 游戏内已收到礼包。
