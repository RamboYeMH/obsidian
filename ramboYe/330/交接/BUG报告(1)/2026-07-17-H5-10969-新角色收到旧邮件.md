# H5-10969：【1046】【邮件】线上创建角色能收到以前的邮件

## 问题概述

- **工单**: H5-10969
- **报告人**: huangdaxin
- **经办人**: wenyu
- **环境**: 线上 c102（主服 id 282）
- **问题数据**: 小号 ID 10703971，创建时间 2026/7/15
- **现象**: 线上创建角色后能收到以前玩家发送的邮件（小号能领到老邮件）
- **期望**: 新创建的角色不应能收到以前玩家发送的邮件

## 根因

**PF 邮件服务的 `user/mail/group` 注册玩家到服务器邮件组时，没有收到玩家的注册时间戳，无法过滤注册前已存在的旧邮件。**

### 核心链路

```
角色创建 (2026-07-15 15:16:21)
  → PF 平台自动调用: PUT user/mail/group
    args: {mail_group_info: "_3_282", user_id: 10703971, user_type_of_id: 1}
    // _3_282 = MailAddrSyc(3) + serverId(282)
    // ⚠️ 无 RegisterTs 参数！
  → PF 邮件服务无法区分注册前后的邮件
  → 新玩家可见服务器邮件组中所有未过期邮件（含 60 天内的旧邮件）
```

### CSPB 枚举

| 类型 | 值 | 说明 |
|------|-----|------|
| `MailAddrPlayer` | 1 | 个人邮件 |
| `MailAddrUnion` | 2 | 联盟邮件 |
| `MailAddrSyc` | 3 | 系统/服务器邮件 ← 日志中的 `_3_282` |

### 旧系统对比

旧系统（TMS，已废弃）有过滤，新系统（PF）丢失了：

```go
// 旧系统 GetMailSubscribeInfo() — 已废弃但逻辑正确:
system := &mailproto.SubcribeInfo{
    Key:           &mailproto.SubcribeKey{ID: serverID, Type: MailAddrSyc},
    LastTimestamp: p.Stat.RegisterTs,  // ✅ 只收注册后的邮件
}

// 新系统 syncMailGroup() → PF user/mail/group — 当前生效:
pfserv.Cast(&pfproto.UserMailGroupSyncReq{
    OwnerID:   p.PlayerID,
    OwnerType: int32(cspb.MailAddrPlayer),
    Groups:    groups,  // ❌ 无任何时间戳
})
```

### 客户端侧也无兜底

| 函数 | 文件 | 行号 | 问题 |
|------|------|------|------|
| `PackMailHeadList` | `game/play/internal/packproto.go` | 227 | 直接透传 PF 返回的所有邮件 |
| `OnMailBoxNtf` | `game/play/internal/ctl_mail.go` | 627 | 邮箱通知直接推客户端 |
| `syncMailGroup` | `game/play/internal/ctl_mail.go` | 125 | `UserMailGroupSyncReq` 无时间字段 |

## 修复建议

**方案 A（推荐）: PF 侧过滤**

`UserMailGroupSyncReq` 增加 `RegisterTs` 字段，PF 后端根据注册时间过滤邮件：

```go
// game/play/internal/ctl_mail.go syncMailGroup 修改:
pfserv.Cast(&pfproto.UserMailGroupSyncReq{
    OwnerID:    p.PlayerID,
    OwnerType:  int32(cspb.MailAddrPlayer),
    Groups:     groups,
    RegisterTs: p.Stat.RegisterTs,  // 新增
})
```

**方案 B（兜底）: 游戏服侧过滤**

如果不能改 PF，在 `PackMailHeadList` 中过滤：

```go
// game/play/internal/packproto.go:
func (play *Play) PackMailHeadList(p *mplayer.Player, mails []*mailproto.Mail) []*cspb.MailHead {
    ret := make([]*cspb.MailHead, 0, len(mails))
    for i := 0; i < len(mails); i++ {
        if mails[i].CreatedAt < p.Stat.RegisterTs {
            continue  // 过滤注册前的邮件
        }
        ret = append(ret, play.PackMailHead(p, mails[i]))
    }
    return ret
}
```

## 影响范围

所有在运营中服务器（非新服）创建的新角色，都可能收到服务器邮件组中未过期的旧邮件。60 天邮件过期窗口内最明显。
