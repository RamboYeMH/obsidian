# 远征采集中被强制遣返回原服（王战结算误伤）

- 日期：2026-09-07
- 区服：700 / 角色：9085231（都叫好）
- 严重级：P2（体验问题，无数据损坏）

## 现象
玩家在远征（cross1005 exp 地图 6001）采集中，9/6 14:00 被强制召回原服 game700。

## 时间线（证据）
| 时刻 | 事件 |
|------|------|
| 12:52 / 13:02 | 玩家进入 cross1005 远征地图（聊天室 `reserved\|h5\|1005\|exp`，8 编队出城采集） |
| 13:59-14:00 | 8 支编队均在采集中（elapseMs≈104min，is full load:false 未满载） |
| 14:00:04 | cross1005: `deporting player 9085231 from server 700`（ctl_king_war.go:3220 timerDeportPlayer） |
| 14:00:04-06 | game700 play: `RecallPlayerTroop` + `W2PDeportPlayerReq`（ctl_king_war.go:698） |
| 14:00:10-14 | `OnP2MDeportOnForceRecallOverReq changemap` 强制换图 |
| 14:00:20-21 | 回到 game700 原服，远征城 `OnP2MCityKickOut IsCross:true` |

同波次共 9 名外服玩家（pid 89x-91x 段为主）被同时遣返。

## 根因
跨服入侵（王战）周结算（周日 14:00）进入 `ActvCrossInvadeResult` 阶段：

1. play 侧 `onS2SA2GActvCrossInvadeStageReq`（ctl_cross.go:85-86）cast `S2SPlayDeportPlayerReq`
2. wmap 侧 `OnS2SPlayDeportPlayerReq` → `KingWarDeportBackForce()`（ctl_king_war.go:3234）
3. 该函数遍历 **WildMap 主地图 MapPlayers**，凡 `ServerID != conf.ServerID` 一律加入 DeportList 遣返，**不检查玩家当前实际所在地图**

玩家此前参与过本周期跨服入侵（在主地图留有 MapPlayer 记录，ServerID=700），随后转入远征地图采集。王战结算时他被从远征场景中途拉回。

对照组：14:04 仍有其他玩家（3028134/8963694 等，本组服 1005 玩家）在远征正常采集——`ServerID == conf.ServerID` 不受影响。

## 结论
- 非数据 bug，无兵量/资源损失（部队召回正常结算）
- 属**设计缺陷**：王战结算遣返不豁免正在远征等其他副本地图的外服玩家

## 建议（服务端，按代价分级）
1. 最小改动：`KingWarDeportBackForce` 遍历时跳过"当前不在主 WildMap"（在远征/其他副本）的玩家，待其副本结束自然回图时再遣返或直接放行
2. 或遣返前检查玩家当前 map，若在 exp 副本则仅清 DeportList 延后处理

## 运营回复口径
周日 14:00 跨服入侵（王战）周期结算，系统统一遣返外服玩家；该玩家虽在远征采集中，但因本周期参与过王战被一并召回。无资源损失，采集进度中断属已知设计缺陷，已提交程序侧评估修复。
