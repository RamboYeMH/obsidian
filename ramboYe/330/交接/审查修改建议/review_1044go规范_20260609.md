### P2 · 规范22/L7 — autoUseItemOnLogin 返回值只记日志不判断

**位置：** `game/play/internal/ctl_item.go:1849-1851`

**问题说明：**  
`useItemIceChalcedony` 返回的 `errCode` 被记录日志但没有任何判断处理。对于登录自动使用的功能，失败通常需要有明确的处理策略。

```go
errCode, usedCount := play.useItemIceChalcedony(p, itemCfg, cnt)
tlog.Infof("autoUseItemOnLogin playerID=%v, itemID=%v, count=%v, usedCount=%v, errCode=%v",
    p.PlayerID, autoUseItemID, cnt, usedCount, errCode)
```

目前只是日志记录，不算严格违规（`errCode` 有被使用——记入日志）。但如果 errCode 非 Success，`usedCount` 可能为 0，而道具可能已被消耗（`useItemIceChalcedony` 内无论成功与否都会调用 `DecAsset`），此处缺少对失败情况的告警。

**修改建议：**
```diff
  errCode, usedCount := play.useItemIceChalcedony(p, itemCfg, cnt)
- tlog.Infof("autoUseItemOnLogin playerID=%v, itemID=%v, count=%v, usedCount=%v, errCode=%v",
-     p.PlayerID, autoUseItemID, cnt, usedCount, errCode)
+ if errCode != cspb.ErrCodeSuccess {
+ 	tlog.Warnf("autoUseItemOnLogin failed playerID=%v, itemID=%v, count=%v, errCode=%v",
+ 		p.PlayerID, autoUseItemID, cnt, errCode)
+ } else {
+ 	tlog.Infof("autoUseItemOnLogin playerID=%v, itemID=%v, count=%v, usedCount=%v",
+ 		p.PlayerID, autoUseItemID, cnt, usedCount)
+ }
```
