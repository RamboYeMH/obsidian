# 实际运行前核对

仅在即将启动真实机器人运行时读取。

- 先列角色及操作依赖；申请/审批、交易、组队等按角色准备最小数量，不等跑到中途再发现缺少对手或管理员。新增角色用于业务覆盖，不能用于绕过限额。
- 逐项确认场景、资源、身份权限及核验入口。GM 的作用对象必须与目标玩家一致；读实现和回包，不把命令返回 ok 当作准备完成。
- 首次编排读取当前 MCP 的运行数据契约，确认 global/session/local、int64 字符串、Extract 字段路径及 Wait 参数。复用已验证小 Block，不反复手写登录。
- 记录每阶段角色 ID、Run ID、已成功写入的业务动作及未执行步骤。断言失败可能发生在写入成功之后，修编排后先回读真实状态再续接；结果未知不得重发写请求。
- 遇到额度限制使用服务器返回的恢复时间；旧实例再结合已知启动记录判断。不以换号、换草稿或重启清额度。已有授权无需重复询问是否继续，用户中断或明确停止时停止等待。
- 客户端已负责轮询与分页；Agent 只读取业务摘要和必要字段。敏感证据不能整包打印，使用 read-evidence 的状态、类型与字段筛选。
